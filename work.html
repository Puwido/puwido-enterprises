Anti-cheat · 01 of 06

Warden — Anti-Cheat

A server-side anti-cheat for Roblox. It catches speed, fly, noclip, teleport and remote exploits, snaps cheaters back the moment they try something, and builds up evidence over time so real players aren’t punished for lag. Everything runs on the server, and nothing the client says is taken on trust — deleting a local script won’t turn it off.

  • Movement checked against the server’s own walk speed, so changing it client-side does nothing
  • Catches teleporting, flying, hovering, infinite jumping, walking through walls, clipping into parts and fling exploits
  • Pulls offenders back to their last legitimate position, so cheating gets them nowhere
  • Per-remote rate limits with server-wide flood protection; rejects wrong types, NaN or infinite numbers, oversized strings or tables, and extra arguments
  • Cooldowns, range checks and admin-only gating on remotes, plus fake remotes and two-way decoy traffic that expose remote-spies and replay attempts
  • Blocks equipping several tools at once, respawns players who remove their Humanoid or root part, and logs or reverts unauthorised changes to protected values like currency
  • Graduated punishments — log, warn, restrict, kick, ban — driven by a decaying suspicion score, so a single glitch or lag spike won’t kick anyone; bans go through Roblox’s official ban system
  • In-game /ac commands to check status and history, restrict, kick, ban, unban or grant a temporary exemption, with detection and admin-action logs kept between sessions
  • Modular with a single settings file and a simple API — RegisterRemote, Exempt, Teleport and ProtectValue — on one shared check loop that reacts to events to keep overhead low

Tested with 350 ms of simulated lag with zero false positives.

Security · 02 of 06

Anti-Injection System

Detects unauthorised interfaces added to a player’s PlayerGui and deals with offenders automatically. Each client is scanned 40 seconds after joining, then every 10 minutes, and any interface the game didn’t create is flagged.

  • Three strikes: kick, three-day ban, then permanent ban
  • Strikes saved per account and carried across servers
  • Bans issued through Roblox’s official Ban API
  • Only the player who triggered a detection is punished
  • Draggable admin panel with detection logs, a player list and teleporting
  • Ban or unban by username or UserId; unbanning also clears strikes

Scope: only PlayerGui is scanned, so interfaces placed in CoreGui or hidden containers, or added and removed between scans, are not detected.

Moderation · 03 of 06

Anti-Ageplayer System

Enforces an experience’s avatar standards automatically. Every avatar is checked on spawn and again whenever accessories are added, and players wearing prohibited items are removed without staff needing to step in.

  • Checks accessories, layered clothing, shirts, pants and T-shirts against catalog names and descriptions
  • Whole-word, case-insensitive matching to avoid false positives
  • Exact catalog ID blocking, plus an exemption list for trusted users
  • Admin panel for bans, players and settings — no code edits needed
  • Every admin request verified on the server
  • Ban records and settings saved with DataStores and synced across servers

Moderation · 04 of 06

Anti-NSFW System

Detects and prevents inappropriate behaviour in an experience, including the exploit tools and commands used to act it out.

  • Blocks known inappropriate exploit tools and commands
  • Three strikes: warning, kick from the server, then ban
  • Bans issued through the Roblox Ban API
  • Bans viewable and manageable from the experience’s Moderation page in the Creator Hub

Interface · 05 of 06

Avatar Loading Screen

Shows players their own avatar while the game loads. The progress bar tracks real loading work, so it only reaches 100% when the game is actually ready.

  • The player’s avatar rendered in 3D — R6 and R15, with a headshot or initials fallback
  • Tracks server data, player data, world, assets, systems and character spawn
  • Live checklist showing which stage loading is on
  • Enter button that unlocks only once loading is complete
  • Every stage times out, so nobody gets stuck
  • Works on PC, mobile and console, from phone to ultrawide

Interface · 06 of 06

Custom Loading Screen

A game-ready loading screen that sets the game’s title and tagline over a live 3D scene of the map, giving players a preview of the world before they join.

  • Live 3D background of the actual game scene
  • Weather effects such as falling snow
  • Tips bar with gameplay hints
  • Animated progress bar with a live percentage
  • Status messages and a countdown before the PLAY button
  • Title, tagline, colours and tips all customisable
